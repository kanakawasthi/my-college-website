# MindSpace — Student Website Project

A responsive student-made wellbeing and self-reflection website built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — layout, responsive styling and animations
- `script.js` — interactive features and browser storage

## Features
1. Mood Garden: mood check-in with a small local visual history.
2. Thought Vault: rotating reflection prompts, word count and locally saved journal.
3. Reset Room: paced breathing animation and a two-minute quiet timer.
4. Little-Win Wall: add small positive moments to a local wall.
5. Rotating daily thoughts, responsive navigation and mobile-friendly layout.

## Run locally
Open the folder in VS Code. Open `index.html` in a browser, or use the Live Server extension.

## Publish with GitHub Pages
Create a public repository, upload `index.html`, `style.css`, `script.js` and this README to the repository root. In Settings → Pages, select Deploy from a branch, choose `main` and `/(root)`, then save.

## Notes
This is an educational, student-made concept, not a medical or crisis-support service. The mood check-in is not a diagnosis. Journal entries, mood history and little wins use browser localStorage on the current device and browser; they are not encrypted or synced to an account. Avoid sensitive personal information and do not use private journal features on shared devices. External Google Fonts and the hero image require an internet connection.
